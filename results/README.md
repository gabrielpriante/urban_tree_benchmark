# results/

Evaluation outputs. **Contents are not tracked by Git by default**; only this
README is committed (see `.gitignore`).

## Policy

- Large generated outputs (prediction files, rasters, model outputs, logs) stay
  local and are not committed.
- Small, final summary tables meant for the paper may be committed on purpose,
  after review, by adding a specific exception to `.gitignore`.
- Each result must be traceable to a commit, dataset version, model version,
  and configuration (see `docs/methodology.md`, §4).
- Outputs from the earlier pilot experiments (frozen 2026-11-09) must **not** be copied
  here.
