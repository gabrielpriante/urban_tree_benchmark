# src/

Source code for dataset preparation and model evaluation.

**No code yet.** Code will be added after the dataset investigation and the
methodology are finalized (see `docs/methodology.md`).

## Guidelines

- Keep scripts small and focused. Avoid complex architecture until it is
  needed.
- Read configuration from files or arguments. Do not hard-code paths or
  credentials.
- Every script that produces reported results must record its inputs (dataset
  version, model version, configuration, seed).
- Dependencies will be pinned when the environment is created.
